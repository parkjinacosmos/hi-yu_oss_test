## 🔍 1. 배경 및 필요성

영남대학교 캠퍼스 주변 상권은 매우 넓고 식당의 수가 방대하여, 학생들이 본인에게 딱 맞는 식당 정보를 한눈에 파악하기 어렵습니다. 특히, 기존 포털 사이트의 정보는 무분별한 광고성 리뷰가 많아 실제 대학생들의 생생한 입맛이나 예산(가성비)을 반영하지 못한다는 한계가 있습니다. 

'Hi-yu!'는 이러한 문제점을 해소하고, 학우들에게 광고 없이 신뢰할 수 있는 진짜 상권 정보를 제공하기 위해 기획된 시스템입니다.

<br>

## ✨ 2. Features of "Hi-yu!"

'Hi-yu!'는 학교 구성원 간의 신뢰를 바탕으로, 학생과 소상공인 모두에게 이익이 되는 선순환 구조를 지향합니다.

* **철저한 인증 기반 시스템 (Student)**
    * YU 웹메일 인증을 통해 영남대학교 소속임이 검증된 학생들만 커뮤니티 활동(리뷰 작성 등)이 가능하므로, 광고성 글을 원천 차단합니다.
* **위치 기반 식당 탐색**
    * 학생들이 지도상에서 직접 주요 위치(예: 정문, 오렌지거리 등)를 지정하여 원하는 구역의 식당을 직관적으로 탐색할 수 있습니다.
* **실시간 소통 및 매장 관리 (Owner)**
    * 식당 주인(Owner)은 영남대 학생이라는 명확한 타겟층을 대상으로 실시간 메뉴 상태(품절 여부 등)를 업데이트할 수 있습니다.
    * 학생들의 리뷰에 사장님 답글(피드백)을 남기며 긍정적인 상호작용의 장을 형성합니다.

<br>

## 🎯 3. Project Goals

본 분석(Analysis) 보고서 및 프로젝트의 핵심 목표는 다음과 같습니다.

1.  **사용자 역할 정의**: 주요 사용자층인 학생(Student), 식당 주인(Owner), 관리자(Manager)가 시스템 내에서 어떻게 상호작용하는지 구체적으로 분석하고 정의합니다.
2.  **유스케이스(Use Case) 상세화**: 시스템이 제공하는 각 기능들을 상세히 분석(Description)하여 설계의 정확도를 높입니다.
3.  **도메인 및 UI 모델링**: 분석된 기능을 실제로 구현하기 위해 필요한 핵심 도메인(Domain) 모델을 도출하고, 사용자 인터페이스(UI)의 개념적 구조를 명확히 설계합니다.
